# Prompts dos personagens — Quiz do Reino

Use a mesma IA que criou a arte do canal, **anexando a arte como referência** em cada pedido.
Gere uma imagem por prompt. Salve em `Downloads/QuizDoReino-personagens/` com o nome indicado.

Regras para todas as imagens (já estão dentro de cada prompt):
- Personagem sozinho, corpo inteiro, de frente, centralizado, 1024x1024.
- Fundo liso verde-limão (#00FF00), sem sombra no chão. O fundo eu removo aqui.
- As versões "fechada" e "aberta" de cada um precisam ter **a mesma pose e o mesmo enquadramento**; só a boca muda. É isso que faz a boca mexer na fala.
